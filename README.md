# Анализ продаж интернет-магазина и RFM-сегментация покупателей

Учебный проект по исследованию транзакционных данных интернет-магазина. В проекте выполнена предобработка данных, исследована динамика продаж, проведён анализ стран и товарного ассортимента, а покупатели разделены на сегменты с помощью RFM-анализа.

## Цель проекта

Изучить структуру и динамику продаж, определить основные рынки и товары по выручке, а также выделить группы покупателей с разным покупательским поведением.

## Инструменты

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Данные

Используется датасет **Online Retail II** из [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii).

Источник: Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository. [https://doi.org/10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D). Лицензия датасета — **CC BY 4.0**.

Ноутбук загружает первый лист Excel-файла командой `pd.read_excel('online_retail_II.xlsx')`. Поэтому текущий анализ охватывает период **с 1 декабря 2009 года по 9 декабря 2010 года**, а не весь период исходного датасета.

### Как получить данные

1. Скачайте файл `online_retail_II.xlsx` со страницы [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii).
2. Поместите файл в ту же папку, где находится `retail_sales_rfm_analysis.ipynb`.
3. Не переименовывайте файл: ноутбук ожидает имя `online_retail_II.xlsx`.

Исходный Excel-файл не включён в репозиторий. Он доступен по ссылке выше; это позволяет не хранить копию исходных данных в GitHub-проекте.

## Что сделано

### 1. Предобработка данных

- Проверены размеры и типы данных, пропуски, дубликаты и аномальные значения.
- Исключены строки с номером счёта, начинающимся на `C`.
- Оставлены записи с положительными значениями `Quantity` и `Price`.
- Удалены полные дубликаты.
- Рассчитана стоимость строки: `TotalPrice = Quantity * Price`.
- Общие показатели продаж считаются по всем оставшимся строкам, включая служебные позиции, если они прошли общую очистку.
- Созданы два набора данных: `sales_clean` для анализа продаж и `rfm_data` для RFM-анализа покупателей с известным `Customer ID`.

### 2. Исследовательский анализ данных (EDA)

- Рассчитаны общая выручка, количество заказов, проданных единиц и средняя сумма заказа.
- Изучена динамика выручки и количества заказов по месяцам.
- Сравнены продажи по странам.
- Определены товары с наибольшей выручкой; служебные позиции исключены из товарного рейтинга.

### 3. RFM-анализ

Для каждого покупателя рассчитаны:

- **Recency** — количество дней с последней покупки;
- **Frequency** — количество уникальных заказов;
- **Monetary** — сумма `TotalPrice` по покупателю.

Покупателям присвоены оценки R, F и M, после чего они распределены по шести сегментам: Champions, Loyal Customers, Potential Loyalists, New Customers, At Risk и Hibernating.

Для Frequency использованы собственные диапазоны (1; 2–3; 4–7; 8 и более заказов), поскольку значительная часть покупателей совершила только одну покупку. Границы сегментов являются правилами, выбранными для этого учебного проекта.

### Общие показатели

| Показатель | Результат |
|---|---:|
| Выручка после очистки | £10,271,762.66 |
| Уникальные заказы | 20,951 |
| Продано единиц товара | 5,812,947 |
| Покупатели с известным `Customer ID` | 4,312 |
| Средняя сумма заказа | £490.28 |

### Ключевые наблюдения

- На Великобританию приходится около **85.8%** выручки.
- Наибольшая месячная выручка зафиксирована в ноябре 2010 года — около **£1.46 млн**.
- Среди товаров с наибольшей выручкой лидируют `REGENCY CAKESTAND 3 TIER` и `WHITE HANGING HEART T-LIGHT HOLDER`.

### Распределение RFM-сегментов

| Сегмент | Покупатели | Доля |
|---|---:|---:|
| Hibernating | 1,726 | 40.0% |
| Champions | 1,106 | 25.6% |
| Potential Loyalists | 911 | 21.1% |
| Loyal Customers | 366 | 8.5% |
| New Customers | 117 | 2.7% |
| At Risk | 86 | 2.0% |

В рамках выбранной сегментации крупнейшую группу составляют Hibernating. Для бизнеса это может быть основанием рассмотреть кампании по возвращению неактивных покупателей. Champions — важная группа для поддержания лояльности, а Potential Loyalists могут стать целью коммуникаций, стимулирующих повторные покупки.

## Как запустить проект

1. Установите Python.
2. Скачайте исходный файл `online_retail_II.xlsx` и положите его рядом с ноутбуком.
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Откройте `retail_sales_rfm_analysis.ipynb` и выполните ячейки сверху вниз.

## Ограничения и допущения

- Данные в этом анализе охватывают период только до 9 декабря 2010 года; декабрь представлен не полностью.
- Строки без `Customer ID` остаются в общем анализе продаж, но не участвуют в RFM-сегментации.
- Служебные позиции исключены только из рейтинга товаров. Общая выручка по странам и месяцам, а также `Monetary` в RFM рассчитываются по всем строкам после общей очистки, включая сервисные позиции (`Manual`, `POSTAGE` и другие), если они остались в данных. Поэтому эти показатели отражают суммы учтённых транзакционных строк, а не исключительно стоимость обычных товаров.
- RFM-пороги и правила сегментации выбраны для учебного анализа и не проходили проверку на реальных маркетинговых кампаниях.
- Рассчитанная выручка не является прибылью: в данных нет информации о себестоимости.
